# Architectural Decision Records

AssureCTL records decisions that affect protocol semantics, trust boundaries, compatibility, or public behavior.

## Status values

- **Proposed:** under review and not yet binding.
- **Accepted:** current project direction.
- **Deprecated:** retained for history but discouraged.
- **Superseded:** replaced by a newer ADR, which must be linked.

Files use zero-padded sequence numbers: `NNNN-short-title.md`. Accepted ADRs are not silently rewritten when direction changes; create a replacement ADR and mark the previous record superseded.
