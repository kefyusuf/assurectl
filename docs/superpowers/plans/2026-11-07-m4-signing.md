## Global Constraints

- Every step is test-first: RED must fail for the intended reason; all tests are offline.
- Production changes: new `internal/attestation` (statement, DSSE, PAE, Ed25519 sign/verify, trusted root), new `cmd/assurectl` subcommands (`sign-receipt`, `verify-receipt`), `examples/signed/` conformance fixtures. No changes to `internal/receipt`, `internal/evaluation`, `internal/decision`, `internal/domain`, `internal/gitsubject`, existing schemas, `go.mod`.
- Standard-library crypto only (`crypto/ed25519`, `crypto/sha256`); DSSE PAE byte-exact per the specification; no custom primitives (ADR-0006).
- Fail closed everywhere: any tamper, unknown key, expired issuer, or digest mismatch rejects with no output on stdout.
- Cross-version gofmt (both toolchains on a clean LF view) before every push.
